## 0.2.2 - 2026-11-25

Commit `1cc52d773c22`; release record `pub:sha2-256:nezq6stsmvug5nm5fnetgcpxjmnbxnmasokj2wloxjlhxbtjcblq`.

### Added
- pubfleet owns a state file's SLA block (version 1, chained transformers): tiers named once, each with deadline_seconds and maybe heartbeat_seconds, misses (at least 2) and uptime_minutes, and each service's senders' and address's tiers; pubfleet sla --derive prints each sender's absence window (misses × heartbeat + 180 s), each address's uptime check (half the tier's minutes, three regions, alarm on two failing twice) and the derived variables as JSON, and sla --budget counts them against Cloud Monitoring's free tiers
- pubfleet variables gives each service the CALL_LOG_DEADLINE_SECONDS (and while observability judges silence its OBSERVABILITY_SENDERS; never CALL_LOG_HEARTBEAT_SECONDS, the call log's file heartbeat, which stays the state's) its SLA block derives, leaving one alone while undeclared; pubfleet state --check refuses an unsound SLA block, one past a free tier, and a variable set beside it
- pubfleet derives each service's CALL_LOG_METRIC_SECONDS from its SLA block: the tightest heartbeat_seconds of its senders that have one, the interval of integrations' heartbeat metric
- pubfleet variables reads a repository's variables block of version 2 (pubrules 0.49.1, now the floor): a state value equal to a name's default is satisfied with GitHub holding nothing or an empty value, and said as information only, never a failure; an empty variable counts as unset

### Internal
- The suite's scenarios are Given/When/Then on pubtest's steps
